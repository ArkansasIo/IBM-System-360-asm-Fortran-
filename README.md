# IBM System/360 Complete Program & Data System

Educational/archival project containing IBM System/360-style Assembly, FORTRAN IV,
JCL, symbolic logic, fixed-record data, MySQL schemas, Excel workbooks, tests,
documentation, and host-side conversion utilities.

## Important compatibility note
Exact syntax and available utilities varied by System/360 model, operating system,
assembler, and FORTRAN compiler release. These files are organized as a portable
starting point and should be validated against the intended OS/compiler/emulator.

## Project layers
ASM -> FORTRAN -> JCL -> sequential/fixed-record datasets -> CSV -> MySQL/Excel.
