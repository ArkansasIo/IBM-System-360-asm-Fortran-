# Excel Reports

The source project includes `system360_report.xlsx` locally. The GitHub connector used for this upload accepts UTF-8 text files but does not provide a binary-file upload operation, so the XLSX binary is retained in the generated project package rather than uploaded here.

The workbook structure is documented in `docs/excel/EXCEL_MAPPING.md`, and the underlying CSV/SQL data is included in `data/` and `mysql/`.
