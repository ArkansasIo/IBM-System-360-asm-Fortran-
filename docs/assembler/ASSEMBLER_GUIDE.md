# System/360 Assembler Guide

Core concepts represented in this project:

- CSECT — control section
- USING — establishes addressability
- STM/LM — register save/restore
- MVC — move character data
- LA/L/LR — address/load/register operations
- A — fixed-point addition
- WTO — write-to-operator message in environments supporting it

Always consult the target assembler's macro and linkage conventions before execution.
