# Directory Map

- asm/ — assembler source and macros
- fortran/ — FORTRAN programs and libraries
- jcl/ — jobs, procedures, includes
- logic/ — formal rules and truth tables
- data/ — input/output/fixed records/copybooks
- mysql/ — relational representation
- excel/ — spreadsheet representation
- docs/ — system documentation
- tests/ — test vectors and golden results
- scripts/ — modern host conversion utilities
